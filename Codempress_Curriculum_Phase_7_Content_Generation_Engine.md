# Codempress Curriculum v1

# Phase 7 --- Content Generation Engine

> Phase 7 defines how Codempress creates, reviews, versions, and updates
> educational content at scale while maintaining consistent quality.

------------------------------------------------------------------------

# Vision

The ontology defines **what** to teach.

The blueprint defines **when** to teach.

The Content Generation Engine defines **how** every lesson is produced.

``` text
Ontology
    │
    ▼
Blueprint
    │
    ▼
Lesson Generator
    │
    ▼
Expert Review
    │
    ▼
Published Curriculum
    │
    ▼
Continuous Improvement
```

------------------------------------------------------------------------

# Content Pipeline

For every topic:

1.  Learning Objectives
2.  ELI5 Explanation
3.  Beginner Lesson
4.  Intermediate Lesson
5.  Advanced Lesson
6.  Real-world Examples
7.  Interactive Exercises
8.  Quiz
9.  Coding Challenge
10. Mini Project
11. Capstone Contribution
12. AI Tutor Prompt
13. Interview Questions
14. Revision Notes
15. Mastery Checklist

------------------------------------------------------------------------

# Universal Lesson Template

Every lesson contains:

## Metadata

-   Lesson ID
-   Topic ID
-   Version
-   Difficulty
-   Estimated Duration
-   Prerequisites

## Learning

-   Why this matters
-   Learning outcomes
-   ELI5 explanation
-   Core concepts
-   Visual analogy
-   Common mistakes

## Practice

-   Guided example
-   Independent exercise
-   Debugging task
-   Stretch challenge

## Validation

-   Quiz
-   Coding assessment
-   AI oral interview
-   Reflection

-   Draft lessons

-   Code snippets
