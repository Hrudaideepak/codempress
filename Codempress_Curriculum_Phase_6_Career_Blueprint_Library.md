# Shared Project Library

Projects are tagged by:

-   Difficulty
-   Technologies
-   Careers
-   Estimated Hours
-   Portfolio Value
-   Interview Value

Example:

Expense Tracker - Beginner - Python - Backend - SQL

AI Resume Analyzer - Intermediate - FastAPI - LLM - Vector DB

Enterprise SaaS - Advanced - Cloud - CI/CD - Kubernetes

# Certification Mapping

mandatory.
