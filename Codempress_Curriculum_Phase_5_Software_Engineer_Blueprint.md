# Curriculum Structure

## Level 0 --- Computer Literacy (ELI5)

Goal: Understand what a computer is and how software works.

Topics: - What is a computer? - Hardware vs Software - Files & Folders -
Operating Systems - Keyboard & Terminal Basics - Internet Basics

Project: - Organize files and create a simple personal workspace.

Assessment: - Basic digital literacy quiz.

------------------------------------------------------------------------

## Level 1 --- Programming Foundations

Topics: - Computational Thinking - Variables - Data Types - Conditions -
Loops - Functions - Objects - Error Handling

Language: - Python (recommended) - Optional: JavaScript

Projects: - Calculator - Number Guessing Game - Todo CLI

------------------------------------------------------------------------

## Level 2 --- Problem Solving

Topics: - Arrays - Strings - Hash Maps - Linked Lists - Stacks -
Queues - Trees - Graphs - Sorting - Searching - Big-O

Projects: - Contact Manager - Library Management

Interview: - Beginner DSA

------------------------------------------------------------------------

## Level 3 --- Web Engineering

Topics: - HTML - CSS - JavaScript - TypeScript - Git - GitHub - HTTP -
REST APIs

Projects: - Portfolio Website - Blog - Weather App

------------------------------------------------------------------------

## Level 4 --- Backend Engineering

Topics: - FastAPI / Express - Authentication - Authorization -
PostgreSQL - ORM - API Design - Testing

Projects: - Task Manager API - E-commerce Backend - Authentication
Service

------------------------------------------------------------------------

## Level 5 --- Production Engineering

Topics: - Docker - CI/CD - Cloud Basics - Monitoring - Logging -
Security - Performance - Caching

Projects: - Deploy a production-ready application.

------------------------------------------------------------------------

## Level 6 --- System Design

Topics: - Scalability - Load Balancing - Message Queues -
Microservices - Distributed Systems - CAP Theorem - Caching Strategies

Projects: - Design YouTube - Design WhatsApp - Design Uber

------------------------------------------------------------------------

## Level 7 --- Senior Software Engineer

Focus: - Code Reviews - Technical Leadership - Mentoring -
Architecture - Cross-team Collaboration - Performance Optimization

Deliverables: - Lead medium-sized products. - Mentor junior engineers.

------------------------------------------------------------------------

## Level 8 --- Staff Engineer

Focus: - Organization-wide Architecture - Platform Engineering -
Developer Experience - Engineering Standards - Cross-functional
Influence

Deliverables: - Drive technical direction across multiple teams.

------------------------------------------------------------------------

## Level 9 --- Principal Engineer

Focus: - Long-term Architecture - Engineering Strategy - Emerging
Technologies - Business Alignment - Technical Vision

Deliverables: - Define engineering direction for the organization.
