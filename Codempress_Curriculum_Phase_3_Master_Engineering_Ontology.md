# Codempress Curriculum v1

# Phase 3 --- Master Engineering Ontology & Skill Taxonomy

> This document defines the complete taxonomy of engineering knowledge
> used by Codempress. Every lesson, roadmap, AI recommendation,
> assessment, and project maps back to this ontology.

------------------------------------------------------------------------

# Purpose

The ontology answers four questions:

1.  What does the learner know?
2.  What should they learn next?
3.  Which careers require this skill?
4.  How proficient are they?

------------------------------------------------------------------------

# Taxonomy Hierarchy

``` text
Domain
 └── Category
      └── Module
           └── Topic
                └── Subtopic
                     └── Concept
                          └── Lesson
                               └── Skill
                                    └── Assessment
```

-   Prerequisites
