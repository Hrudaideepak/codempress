# Clean Architecture & Refactoring Skill

Use this skill when restructuring monolithic or tangled code to enforce separation of concerns without altering user-visible behavior.

## Core Rules

1. **Separation of Concerns**
   - Entities / Domain Core: Business rules (zero dependencies).
   - Use Cases / Application Services: Application logic.
   - Interface Adapters: Controllers, Repositories, Presenters.
   - Frameworks & Drivers: FastAPI, React, SQLite, External APIs.

2. **SOLID Principles**
   - Single Responsibility Principle (SRP).
   - Open/Closed Principle (OCP).
   - Liskov Substitution Principle (LSP).
   - Interface Segregation Principle (ISP).
   - Dependency Inversion Principle (DIP).

3. **Deliverables**
   - Modernized Folder Structure
   - Clean Architecture Tier Breakdown
   - Production-Grade Refactored Code
   - Architectural Improvement Summary
