# UI Systems & Component Engineering Skill

Use this skill when building modern frontend design systems, reusable UI components, layout engines, and interactive web applications.

## Component Engineering Guidelines

1. **Accessibility (a11y)**
   - WAI-ARIA roles, attributes (`aria-expanded`, `aria-label`, `aria-busy`).
   - Full keyboard navigation (`Tab`, `Enter`, `Escape`, Arrow keys).

2. **Component Lifecycle & States**
   - Loading Skeletons / Spinners.
   - Empty States with actionable call-to-actions.
   - Error Boundaries & Fallback Displays.
   - Responsive breakpoints & fluid typography.

3. **Developer Experience (DX)**
   - Strict TypeScript interfaces or well-documented JSDoc prop contracts.
   - Modular CSS / Tailwind / CSS variables design system.

4. **Deliverables**
   - Component Architecture Overview
   - Props / API Contract Design
   - Production-Ready React/CSS Component Implementation
   - Usage Examples & Integration Patterns
