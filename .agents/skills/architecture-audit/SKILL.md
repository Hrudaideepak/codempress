# Reverse-Engineering & Architectural Audit Skill

Use this skill when auditing unfamiliar or complex codebases to map architecture, detect bad decisions, and propose clean refactorings without altering functionality.

## Workflow

1. **Understand Architecture & Data Flow**
   - Trace entry points, API boundaries, service layers, database access, and UI rendering.
   - Build a mental map or Mermaid flow of data and control.

2. **Identify Issues**
   - Bad architectural decisions & tight coupling.
   - Duplicate logic across modules.
   - Performance bottlenecks & N+1 queries.
   - Scalability risks & memory/concurrency issues.
   - Maintainability & developer experience gaps.

3. **Deliverables**
   - Clean Architecture Breakdown
   - Critical Problem Areas Analysis
   - Refactoring Strategy
   - Production-Grade Refactored Code (zero functional changes)
