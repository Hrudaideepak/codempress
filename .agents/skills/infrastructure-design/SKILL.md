# Systems Infrastructure Design Skill

Use this skill when designing high-growth startup infrastructure, distributed systems, API gateway layers, database replication/sharding strategies, and caching topologies.

## Key Blueprint Elements

1. **High-Level System Architecture**
   - Client Tier (Web/Mobile/Desktop)
   - API Gateway & Load Balancing
   - Microservices / Modular Monolith
   - Data Tier (Primary DB, Read Replicas, Caching, Search Index)
   - Event Bus / Queue (RabbitMQ, Kafka, Redis Streams)

2. **Data & Caching Strategy**
   - Cache invalidation patterns (Write-through, Cache-aside).
   - Database partitioning, indexing, schema design, constraints.

3. **Deliverables**
   - System Architecture Diagram
   - Component & API Specification
   - Data Flow & Caching Strategy
   - Database Schema
   - Production Implementation Blueprint
