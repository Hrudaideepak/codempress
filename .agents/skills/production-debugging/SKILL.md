# Production Outage Debugging & Root Cause Analysis Skill

Use this skill when investigating critical production failures, unhandled exceptions, race conditions, or unexpected system behavior.

## Investigation Protocol

1. **Step-by-Step Execution Trace**
   - Read un-truncated logs and stack trace lines carefully.
   - Trace exact execution paths, data mutations, and async boundaries.

2. **Root Cause Analysis**
   - Identify why the failure occurred at the foundational level.
   - Separate symptoms from root causes.
   - Analyze hidden edge cases (e.g., null values, network timeouts, race conditions, concurrent access).

3. **Deliverables**
   - Code Functionality Breakdown
   - Empirical Root Cause Analysis
   - Failure Mechanism Explanation
   - Comprehensive Edge-Case Analysis
   - Fixed, Production-Ready Code with defensive validation
