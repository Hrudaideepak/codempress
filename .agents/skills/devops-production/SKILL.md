# DevOps & Production Deployment Skill

Use this skill when creating build pipelines, containerizing services, establishing health monitoring, or preparing production release infrastructure.

## Core Directives

1. **Containerization & CI/CD**
   - Multi-stage Dockerfiles (optimized size, non-root user).
   - GitHub Actions workflow (linting, automated test runs, Docker build, deployment trigger).
   - Infrastructure configurations (Render, Vercel, Kubernetes manifests).

2. **Observability & Resiliency**
   - Health check endpoints (`/api/health`, `/api/ai/status`).
   - Centralized logging & structured JSON log outputs.
   - Alerting thresholds, graceful shutdown handling, zero-downtime rollouts.

3. **Deliverables**
   - Production Infrastructure Topology
   - Automated CI/CD Workflow Yaml
   - Docker / Deployment Configs
   - Monitoring & Alerting Plan
   - Pre-Flight Production Checklist
