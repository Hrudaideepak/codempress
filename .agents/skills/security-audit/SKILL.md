# Security Audit & Risk Mitigation Skill

Use this skill when performing security reviews, penetration audits, API security checks, or hardening authentication/authorization mechanisms.

## Audit Matrix

1. **Vulnerability Assessment**
   - Injection Risks: SQLi, NoSQLi, Command Injection, Prompt Injection.
   - Authentication & Authorization: JWT validation, Google OAuth audience checks, missing RBAC/ABAC gating.
   - Client Side Security: XSS (DOM/Reflected), CSRF, insecure localStorage tokens.
   - Infrastructure & API: SSRF, CORS misconfigurations, unthrottled endpoints (DDoS / Brute Force).

2. **Reporting & Fixes**
   - Severity Level (Critical, High, Medium, Low).
   - Real-World Attack Scenario.
   - Production-Grade Hardening Code.
