# Performance Optimization & Profiling Skill

Use this skill when optimizing backend throughput, frontend render performance, database queries, memory utilization, or network overhead for high-traffic scale.

## Optimization Protocol

1. **Bottleneck Identification**
   - Measure Big-O time and space complexity.
   - Detect N+1 queries, unindexed database scans, blocking loop operations, or redundant re-renders.
   - Uncover memory leaks, unclosed subscriptions, or bloated bundle sizes.

2. **Optimization Strategies**
   - Caching (in-memory, Redis, HTTP headers).
   - Database query batching, indexing, and selective fetching.
   - React component memoization (`React.memo`, `useMemo`, `useCallback`), virtualization, code splitting.
   - Algorithmic optimization from $O(N^2)$ to $O(N)$ or $O(\log N)$.

3. **Deliverables**
   - Performance Issue Breakdown
   - Optimization Strategy Overview
   - Production-Ready Optimized Code
   - High-Traffic Scalability Recommendations
